# M4 STM32 hardware results, 2026-11-28

The maintainer authorized reprogramming the connected Three Blue Whales
Elite ME V6 and confirmed its 8 MHz HSE and USART1 routing to COM5.
SWD read CPUID 0x411fc231, STM32 IDCODE 0x10036414 and Flash size 512 KiB.
Automatic chip identification failed with SWD AP wait. Explicit
STM32F103ZETx and 100 kHz SWD worked. probe-rs 0.32.0 verified each
download. No mass erase was requested.

Firmware source is `f341189` on the M4 branch. The later LF-only
normalization was rebuilt and compared in binary form using
`llvm-objcopy -O binary` for each board profile. Flash bytes matched.
The SHA-256 values below identify the ELFs actually downloaded.
Raw SWD, UART, Verify, hashes and local logs remain under
`target/m4-evidence/` in the development workspace.

rejection code 2 and zero completion marker.

configuration, M2 SysTick timebase and M3 memory self-tests. TLSF profiles
also ran the M3 allocation smoke tests. Dedicated M0–M3 fault injection
and stress regression profiles were rebuilt and inspected locally under
M4. They were not reflashed for this run.

with status 0. The subsequent SWD snapshot confirms 1,000,007 handoffs,

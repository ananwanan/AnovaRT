The following PowerShell commands regenerate the inspection logs in the ignored target directory. Both LLVM commands exited 0.

```powershell
$llvm = Join-Path (rustc --print sysroot) 'lib/rustlib/x86_64-pc-windows-msvc/bin'
$elf = 'target/thumbv7m-none-eabi/release/anova-firmware'
& (Join-Path $llvm llvm-readobj.exe) --file-headers --sections --program-headers $elf |
  Set-Content target/m0-elf.txt
& (Join-Path $llvm llvm-objdump.exe) -s -j .vectors -s -j .data -d -j .text $elf |
  Set-Content target/m0-disassembly.txt
Get-FileHash $elf
```

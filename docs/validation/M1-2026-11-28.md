# M1 hardware acceptance record

Date 2026-11-28 (UTC+8). Evidence is the maintainer's Serial Studio capture and follow-up bench report. The flashed ELF hash and source commit were not supplied.

Serial Studio received the normal AnovaRT banner on the Elite ME V6 via the ST-Link virtual COM port (COM5) at 115200 baud, 8N1, with flow control disabled. The banner reported HsePll and SYSCLK/HCLK/PCLK1/PCLK2 of 72/72/36/72 MHz.

| Check | Status | Evidence |
|---|---|---|
| Normal boot banner and UART TX | Pass | Four startup lines captured in Serial Studio |
| Normal UART RX/TX | Pass | Maintainer reports that sending a single uppercase U returned U after RESET |
| Normal M1 DS0 | Pass | Maintainer observed continued blinking after RESET |
| Board RESET | Pass | Maintainer reports all four startup lines reappeared, DS0 blinked and U echoed |
| Independent clock and UART timing checks | Pass | Maintainer confirmed the requested clock and baud checks |
| HSE, PLL and clock-switch fault-injection images | Pass | Maintainer confirmed all three HSI recovery runs, including UART echo and DS0 |
| Panic with USART1 | Pass | Maintainer confirmed the panic diagnostics and terminal halt |
| Panic without USART1 | Pass | Maintainer confirmed the no-console terminal halt |
| Debugger-free cold boot | Pass | Maintainer confirmed startup, DS0 and UART echo after power cycling with SWD disconnected |
| Independent M0 regression | Pass | See [local validation](M1-local-2026-11-28.md) for the binary comparison and read-only PB5 samples |

On the follow-up, the maintainer reported that all remaining checks in the [bench procedure](../TESTING.md#m1-hardware-acceptance) passed. Raw timing captures, register values, crystal markings, wiring details and ELF hashes were not provided. The branch tip at closeout was `28b51b9b8156ef12d82c551e02bbd1e352402456`. The exact flashed revision remains unrecorded.

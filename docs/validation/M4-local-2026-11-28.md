## Linked resources

| Image | Flash loaded | Static SRAM | Total reserved SRAM | Unallocated SRAM |
|---|---:|---:|---:|---:|
| Default no-heap | 24,096 | 5,880 | 16,120 | 49,416 |
| Default TLSF | 29,760 | 7,136 | 29,664 | 35,872 |
| HSI no-heap, USART1 | 33,120 | 5,880 | 16,120 | 49,416 |
| HSI TLSF, USART1 | 40,004 | 7,136 | 29,664 | 35,872 |
| HSE no-heap, USART1 | 33,540 | 5,880 | 16,120 | 49,416 |
| HSE TLSF, USART1 | 40,424 | 7,136 | 29,664 | 35,872 |

Bytes, including 5,120 bytes of worker and idle stacks already counted in
static SRAM. The 44-byte TCB and 396-byte eight-slot table are part of the
432-byte runtime object. Two separate 4,096-byte MSP regions and the
2,048-byte pool are present in each image. TLSF reserves 12,288 bytes in
addition, and its 1,256 bytes of allocator metadata are already in static
SRAM. Unallocated SRAM includes linker alignment gaps. Worker peaks are
runtime observations.

Both default images are below the minimum-kernel 32 KiB Flash budget.
The USART1 validation profiles exceed it due to diagnostic formatting,
fixtures and the inherited M3 diagnostics. All images fit the device.
Static SRAM excluding the four application stacks is 760 B (no-heap)
or 2,016 B (TLSF), within the 4 KiB minimum-kernel target. Keep bench
diagnostics feature-gated and size any production task stacks from board
measurements. No chip-region expansion was used.
